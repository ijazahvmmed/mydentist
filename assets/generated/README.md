# Generated source artwork

Original PNG assets generated using the built-in image tool. The production site uses optimized WebP derivatives in `public/images/treatments/`. These are illustrative CGI, not clinic/patient photography or clinically validated diagrams.

## Aligner prompt

Use case: product-mockup. Asset type: decorative website treatment editorial visual. Create a premium studio CGI macro image of one transparent orthodontic clear aligner dental tray, an anatomically plausible U-shaped removable tray with individual tooth impressions, seen in elegant three-quarter view, gently floating, fully in frame, on a perfectly plain dark muted petrol teal background (#21454b). Wide soft highlights show thin clear polymer edges and individual tooth indentations. Clean realistic dental product rendering, no teeth inside, no person, no clinical diagrams, no text, no branding, no ring or torus shape. High-end art direction, restrained, ample negative space, square crop. Illustrative generic aligner, not a specific branded product.

## Tooth prompt

Use case: stylized-concept. Asset type: premium dental website hero visual, decorative illustration only. Create an exquisite studio CGI of one natural adult molar tooth, soft warm ivory enamel with nuanced cusps and roots, realistic external silhouette, subtle satin translucency, floating upright with a very slight tilt, fully visible with generous space around it. Very pale powder blue seamless background (#e7f0f6), diffused daylight, delicate grounding shadow below. Sophisticated luxury medical editorial product photography, restrained, clean. No internal anatomy, no cutaway, no labels, no text, no logos, no face, no cartoon, no chrome, no glass. Square composition, object occupies approximately 70% of image height.
